# Pantheon 1.6.0

Release notes for the 1.6.0 candidate. This page is the short version; the
changelog is the complete record.

## Highlights

- OpenCode 2 works, and `auto` picks the plugin generation from the host.
- V2 tools now run instead of only announcing success.
- Three permission gaps are closed.
- Cost reporting answers money questions by model and by session.
- The installer is reviewable and reversible.

## Upgrade actions

- Update: `npm install -g pantheon-opencode@beta && pantheon-opencode update`.
- Refresh config: `pantheon-opencode init --yes --headless`.
- Verify: `pantheon-opencode doctor`.
- Pin a generation: `npx pantheon-opencode init --opencode-version v2`.

## What's new by capability

- **V2 support:** `auto` prefers explicit input, then the environment, then a host probe; an unreadable host warns once.
- **Permissions:** agent MCP allowlists become native rules that deny by default.
- **Permissions:** read-only agents cannot reach mutating tools on either generation.
- **Cost:** reports add USD, per-model and per-session views.
- **Cost:** `session` scopes a report to a root session and its descendants.
- **Memory:** entries are capped at 64 KiB and can expire; search failures return a typed error.
- **Installer:** apply previews each file, detects drift, and keeps an exact backup.
- **Installer:** `restore`, `reconcile` and `uninstall` cover recovery and removal.

## Fixes

- V2 tools no longer report success without executing.
- Empty child dispatch results surface as errors.
- Offline cost mode refuses an explicit price refresh.

## V2 compatibility

OpenCode **1.19.x** (V1) and **OpenCode 2.x** (V2) are supported; **2.0.22 is known broken**.
See [Compatibility](https://ils15.github.io/pantheon-opencode/compatibility/) for the policy and verified-version evidence.

## Deprecated & removed

- V1 goal tools are soft-deprecated and no longer auto-continue a session.
- The legacy vector memory path and V2 goal tools are gone.
- Persistence no longer exposes twelve KV/context-management tools.

See [UPGRADING.md](../UPGRADING.md) for the exact steps.

## Known issues

- `ask` is not expressible for MCP on OpenCode 2.x; the installer warns and emits no rule.
- `hashline_edit` and `vision_describe` have no host permission gate.
