# Platform Support

Pantheon v1.0 is **OpenCode-only**.

For installation instructions, see [INSTALLATION.md](INSTALLATION.md).

## OpenCode versions

**1.6.x is the last Pantheon line that supports an OpenCode 1.X host. From 1.7
onward every release is a breaking change targeting OpenCode 2.** The policy,
its support matrix and what is verified against which host version are in the
[README compatibility section](../README.md#compatibility-and-support-policy).
